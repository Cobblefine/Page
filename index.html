FAQ

Which Minecraft version does Cobblefine support?

Minecraft: Java Edition 1.21.1 on the Fabric loader.

Do I need to install anything on the server?

No. The modpack is client-side, and it can connect to servers running only Cobblemon and Fabric API.

Is Cobblefine good for low-end PCs?

That is exactly what it is built for — optimization mods and tuned settings reduce stutter and memory usage while boosting FPS.

Can I make it even faster?

Yes. Add the -XX:+UseZGC -XX:+ZGenerational Java arguments in your launcher.

Is Cobblefine affiliated with Cobbled Studios?

No. The modpack was entirely created by fans and has no affiliation with Cobbled Studios.
